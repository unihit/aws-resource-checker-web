CloudShell이 열리지 않아요.

관리자에게 CloudShell 사용 권한을 요청하세요. 회사 정책으로 제한된 경우 승인된 환경에서 실행해야 합니다.

AccessDenied가 나와요.

현재 로그인한 역할의 조회 권한이나 조직 정책을 확인하세요. 아래 JSON은 조회 권한만 정의하며 CloudShell 접근 권한은 별도입니다.

Download file 메뉴가 없어요.

콘솔 하단 도구 모음 대신 CloudShell을 새 탭이나 전체 화면으로 여세요.

키나 결과가 전송되나요?

수집 코드는 공개 사이트에서 내려받습니다. AWS 조회는 CloudShell에서 수행하고 결과는 CloudShell 홈 디렉터리에 저장합니다. 이 웹페이지는 결과를 서버로 전송하지 않습니다.

① CloudShell 열기 ↗
  1. 검은 터미널에 명령어 붙여넣기

    셸 준비가 끝난 후 붙여넣고 Enter를 누르세요. 처음 실행하면 의존성을 설치합니다. 기존 키·프로필 설정은 이번 실행에서 제외하고 콘솔 인증을 사용합니다. 저장된 설정 파일은 변경하지 않습니다.

  2. 표시된 계정이 맞는지 확인

    계정이 맞으면 Enter를 누르세요. 다른 계정이면 n을 입력하고 대상 계정으로 다시 로그인합니다.

  3. 결과 ZIP 다운로드

    완료되면 표시되는 ZIP 전체 경로를 복사합니다. CloudShell 상단 Actions → Download file → 경로 붙여넣기 → Download.

  4. 압축을 풀고 report.html 열기

    Excel은 report.xlsx를 여세요. Summary의 서비스별 차트와 목록 열기에서 각 서비스 시트로 이동할 수 있습니다. 이 페이지에서는 report.json을 선택하세요.
