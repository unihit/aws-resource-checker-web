RESOURCE CHECK
필요한 범위만, 간편하게 조회.
이 화면에서 실행값을 준비하고 GitHub에서 점검을 시작하세요.

        
i
AWS 연결은 GitHub Actions 실행 환경에서 이루어집니다. 이 페이지에는 키나 GitHub 토큰을 입력하지 않으며, 조회 버튼이 AWS에 직접 요청을 보내지는 않습니다.

        
조회 옵션
main 브랜치
데모는 가상 데이터로 보고서 생성 과정을 확인합니다.
계정 ID 미입력
서울: ap-northeast-2 · 도쿄: ap-northeast-1 · 버지니아: us-east-1
여러 리전은 쉼표로 최대 5개, 활성 리전 전체는 all 단독 입력
전체 범위는 VPC·TGW·VPN·S3·IAM·EKS/ECS 등을 추가 조회합니다.

GitHub에서 시작하고,
여기서 결과를 확인하세요.
  1. Run workflow 누르기
    GitHub 로그인이 필요합니다. Branch는 main을 선택하세요.
  2. 준비한 실행값 입력
    mode, aws_account_id, role_name, regions, scope를 이 화면과 똑같이 입력하세요. 자동 입력되지는 않습니다.
  3. 완료 후 보고서 받기
    실행 결과의 Artifacts에서 AWS-Resource-Check ZIP을 다운로드하고 압축을 풉니다.
  4. 보고서 JSON 열기
    아래 메뉴에서 report.json을 열면 리소스와 점검 후보를 볼 수 있습니다. report.html은 바로 열어도 됩니다.
조회 결과는 비공개 저장소의 GitHub 실행 환경·Artifacts에 저장됩니다. 실제 결과를 공개 Pages에 게시하지 않습니다.
